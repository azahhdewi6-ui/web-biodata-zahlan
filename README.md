# 🌊 Biodata Tim: Dewi Azah Hapsoh & Sri Wulandani

Website biodata tim estetik bernuansa **Blue & Cream** yang terinspirasi oleh palet dan visual *Wave to Earth*.

## ✨ Fitur-Fitur Website
- **Aesthetic Dual Palette:** Perpaduan warna biru laut lembut (*soft blue*, *deep midnight blue*) dan krem hangat (*warm ivory cream*).
- **Interactive Switcher / Tab Slider:** Beralih profil dengan mulus antara Dewi Azah Hapsoh dan Sri Wulandani hanya dengan satu klik (atau tombol panah keyboard `←` dan `→`).
- **Foto Profil Asli & Modal Zoom:** Menampilkan foto asli berbingkai polaroid aesthetic dengan fitur klik untuk perbesar foto (*full preview modal*).
- **Biodata Lengkap:**
  - Hobi (*Journaling* untuk Sri, *Musik & Menyanyi* untuk Dewi)
  - Cita-cita (*Aktor / Actress* untuk Sri, *Perawat / Nurse* untuk Dewi)
  - Tombol langsung ke Instagram (`@sriwlandnii`, `@azahh-ajaa`) dan TikTok (`@azahhe_06`)
  - Fitur salin motto & username satu klik dengan toast notification
- **Aesthetic Floating Particles:** Animasi partikel melayang lembut di latar belakang yang menenangkan dan ringan.
- **Wave to Earth Moodboard:** Aksen vintage poster dan cover art indie.
- **100% Responsif:** Tampil proporsional di layar HP, tablet, maupun laptop/desktop.

## 🚀 Cara Menjalankan Website
Cukup buka file `index.html` dengan cara:
1. Klik dua kali (*double click*) file **`index.html`** di Windows File Explorer.
2. Atau klik kanan pada `index.html` > pilih **Open with** > **Google Chrome** / **Microsoft Edge**.
